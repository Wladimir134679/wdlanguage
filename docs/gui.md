# Модуль `sys.gui`: Графический интерфейс на Java Swing

Модуль `sys.gui` предоставляет возможности создания оконных приложений и графических интерфейсов пользователя (GUI) на базе библиотеки **Java Swing** напрямую из WDL-скриптов.

```wdl
import sys.gui as gui

win = new gui.Window(title: "Привет, WDL!", width: 300, height: 150)
win.setLayout(layout: gui.flow())

btn = new gui.Button(text: "Нажми меня")
btn.onClick(handler: def () => gui.alert("Кнопка нажата!", title: "Привет"))

win.add(component: btn)
win.show()
```

Все параметры этого модуля **названы**, поэтому у чисел и строк в скобках видно
назначение: `new gui.Window(title: "…", width: 300)` вместо `new gui.Window("…", 300, 150)`.
Позиционная запись при этом остаётся законной — правила общие для всего языка,
см. [именованные аргументы](functions.md#именованные-аргументы). Готовые примеры —
[`examples/gui/gui_counter.wdl`](../examples/gui/gui_counter.wdl) и
[`examples/gui/gui_todo.wdl`](../examples/gui/gui_todo.wdl).

## Подключение модуля и жизненный цикл

Модуль подключается из стандартного реестра системных модулей:

```wdl
import sys.gui as gui
```

### Автоматическое ожидание закрытия окон
При вызове `win.show()` GUI-окно отображается на экране. Чтобы процесс не завершался сразу после выполнения последней инструкции скрипта, модуль `sys/gui` автоматически отслеживает открытые окна через `WindowTracker` и удерживает выполнение в методе закрытия модуля (`Library.close()`) до тех пор, пока пользователь не закроет все открытые окна GUI.

Также доступны методы явного ожидания:
* `win.showAndWait()` — отображает окно и сразу блокирует поток до закрытия именно этого окна.
* `gui.wait()` / `gui.loop()` — блокирует поток до закрытия всех открытых окон приложения.

## Компоненты UI

### Окно (`Window`)
Главный контейнер приложения (на базе `JFrame`).

* **Конструктор**: `new gui.Window(title = "WDL Window", width = 400, height = 300)`
* **Свойства**: `title` (читается и пишется), `width` и `height` — только для чтения
  и всегда живые: пользователь тянет рамку мышью, и снимок при создании врал бы уже
  через секунду. Менять размер положено `setSize(width, height)`.
* **Методы**:
  * `show()` — показать окно на экране (не блокируя интерпретатор; автоматическая блокировка сработает в конце скрипта).
  * `showAndWait()` — показать окно и заблокировать выполнение до закрытия окна.
  * `hide()` — скрыть окно.
  * `close()` — уничтожить окно.
  * `add(component, [constraint])` — добавить UI-компонент в окно.
  * `setLayout(layout)` — установить менеджер компоновки (например, `gui.border()`, `gui.flow()`).
  * `setSize(width, height)` — изменить размер окна. Пары аксессоров у `JFrame`
    для этого нет, поэтому здесь метод, а не два свойства.
  * `center()` — отцентрировать окно на экране.
  * `onClose(handler)` — зарегистрировать обработчик закрытия окна.

### Панель (`Panel`)
Контейнер для группировки компонентов (на базе `JPanel`).

* **Конструктор**: `new gui.Panel(layout = null)`
* **Методы**:
  * `add(component, [constraint])` — добавить элемент.
  * `setLayout(layout)` — установить менеджер компоновки.

### Кнопка (`Button`)
Обычная кнопка (на базе `JButton`).

* **Конструктор**: `new gui.Button(text = "", enabled = true)`
* **Свойства**: `text`, `enabled` — читают живую кнопку, а не снимок при создании,
  и пишутся прямо в неё: `btn.text = "Готово"` меняет надпись.
* **Методы**:
  * `onClick(handler)` — зарегистрировать функцию-обработчик клика.
  * `doClick()` — нажать программно.

### Текстовая метка (`Label`)
Однострочная текстовая надпись (на базе `JLabel`).

* **Конструктор**: `new gui.Label(text = "", enabled = true)`
* **Свойства**: `text`, `enabled`.
* **Методов** своих нет: всё, что у метки можно спросить и поменять, — это значение,
  а значение отдаёт свойство.

### Текстовое поле ввода (`TextField`)
Однострочное поле для ввода текста (на базе `JTextField`).

* **Конструктор**: `new gui.TextField(text = "", enabled = true)`
* **Свойства**: `text`, `enabled`. Для поля ввода это важно особо: текст меняет
  пользователь, и `field.text` всегда показывает то, что в поле сейчас.
* **Методы**:
  * `onChange(handler)` — обработчик изменения содержимого поля.
  * `onEnter(handler)` — обработчик нажатия клавиши Enter.

### Многострочная текстовая область (`TextArea`)
Текстовое поле со встроенной полосой прокрутки (на базе `JTextArea` + `JScrollPane`).

* **Конструктор**: `new gui.TextArea(text = "", rows = 10, cols = 30, enabled = true)`
* **Свойства**: `text`, `enabled`.
* **Методы**:
  * `append(text)` — добавить текст в конец области.
  * `onChange(handler)` — обработчик изменения содержимого.

### Флажок (`CheckBox`)
Элемент выбора состояния Да/Нет (на базе `JCheckBox`).

* **Конструктор**: `new gui.CheckBox(text = "", checked = false, enabled = true)`
* **Свойства**: `text`, `checked`, `enabled` — `checked` читает живое состояние
  флажка, в том числе поставленное пользователем.
* **Методы**:
  * `onChange(handler)` — обработчик изменения состояния.

### Выпадающий список (`ComboBox`)
Список выбора вариантов (на базе `JComboBox`).

* **Конструктор**: `new gui.ComboBox(items = [])`
* **Методы**:
  * `addItem(item)` — добавить пункт в список.
  * `clear()` — очистить список элементов.
  * `getSelectedIndex()` / `setSelectedIndex(index)` — получить/установить индекс выбранного элемента.
  * `getSelectedItem()` — получить текущий выбранный элемент.
  * `onChange(handler)` — обработчик выбора элемента.

## Менеджеры компоновки (Layouts)

Модуль предоставляет фабричные функции для управления размещением элементов.
Их параметры **названы**, поэтому вместо `gui.grid(2, 3, 4, 4)` можно писать
`gui.grid(rows: 2, cols: 3, hgap: 4, vgap: 4)` и пропускать середину:
`gui.grid(2, 3, vgap: 8)` — см. [именованные аргументы](functions.md#именованные-аргументы).
То же у диалогов (`gui.alert("готово", title: "Отчёт")`), у методов окна
(`win.setSize(width: 800, height: 600)`) и у создания компонентов
(`new gui.Window(title: "Счёт", width: 400)`).

* `gui.flow(align = "center", hgap = 5, vgap = 5)` — размещение элементов друг за другом (`FlowLayout`). Выравнивание `align`: `"left"`, `"center"`, `"right"`.
* `gui.border(hgap = 0, vgap = 0)` — размещение по сторонам света (`BorderLayout`). Элементы добавляются с ограничением: `"North"`, `"South"`, `"East"`, `"West"`, `"Center"`.
* `gui.grid(rows, cols, hgap = 0, vgap = 0)` — табличная сетка элементов (`GridLayout`).
* `gui.vbox()` — контейнер-панель с вертикальным выравниванием.
* `gui.hbox()` — контейнер-панель с горизонтальным выравниванием.

## Модальные диалоговые окна и утилиты

* `gui.alert(text, title = "Информация")` — показывает всплывающее окно сообщения.
* `gui.confirm(text, title = "Подтверждение")` — показывает окно подтверждения с кнопками Да/Нет. Возвращает `true` или `false`.
* `gui.prompt(text, initial = "")` — показывает окно ввода строки. Возвращает введённый текст или `null`, если пользователь отменил ввод.
* `gui.runLater(handler)` — выполняет функцию асинхронно в потоке обработчика Swing EDT.
* `gui.wait()` / `gui.loop()` — явно заблокировать выполнение текущего скрипта до закрытия всех окон GUI.
