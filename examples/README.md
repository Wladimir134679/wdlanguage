# Примеры

Каждый файл запускается отдельно и показывает одну тему целиком. Всё, что здесь
написано, **работает**: примеры прогоняются как есть, а строки, которые должны падать,
оставлены закомментированными вместе с текстом ошибки.

```bash
./gradlew :wdl-cli:installDist
wdl-cli/build/install/wdl/bin/wdl examples/hello.wdl

# или без сборки дистрибутива
./gradlew :wdl-cli:run --args="examples/hello.wdl"
```

## Язык

| Файл | О чём |
|---|---|
| [hello.wdl](hello.wdl) | переменные, объекты, массивы, вывод — с чего начать |
| [types.wdl](types.wdl) | десять типов: `typeof` возвращает дескриптор, `is` по всем типам, `typeof(x) == Тип` против `is`, дескриптор как обычное имя |
| [expressions.wdl](expressions.wdl) | шпаргалка по выражениям: числа, биты, сравнения, обращение |
| [control-flow.wdl](control-flow.wdl) | `if`, `while`, `for`, перебор, `break`/`continue`, области блока |
| [const.wdl](const.wdl) | `const`: заморожено имя, а не содержимое |
| [functions.wdl](functions.wdl) | объявления, `return`, `=>`, анонимные функции, замыкания |
| [defaults.wdl](defaults.wdl) | значения параметров по умолчанию и когда они вычисляются |
| [named-args.wdl](named-args.wdl) | `f(name: value)`: пропуск в середине, свободный порядок, имена в `new` |
| [variadic-args.wdl](variadic-args.wdl) | `*args` и `**named` в заголовке, раскрытие `f(*array)` и `f(**object)`, проброс вызова |

## Классы и трейты

Три файла по возрастанию: сначала один класс, потом цепочка, потом контракты.

| Файл | О чём |
|---|---|
| [members.wdl](members.wdl) | члены значений: свойства и методы у массива, строки, числа и объекта |
| [introspection.wdl](introspection.wdl) | что значение рассказывает о себе: параметры функции, состав класса, трейты |
| [extend.wdl](extend.wdl) | `extend`: свои члены у типа и у класса, и четыре запрета вокруг него |
| [classes.wdl](classes.wdl) | поля и методы, `this`, конструктор, фабрики, класс как значение, класс внутри функции |
| [inheritance.wdl](inheritance.wdl) | `: Родитель(...)`, `super`, виртуальные вызовы, цепочка из трёх уровней, полиморфизм, `is` |
| [traits.wdl](traits.wdl) | трейт-контракт, готовые реализации, состояние в трейте, несколько трейтов, «побеждает последний», момент проверки требований |
| [class-varargs.wdl](class-varargs.wdl) | остаток в заголовке `*args`/`**named`, переброска родителю, почему остаток не поле |

Правило, вокруг которого построен файл про трейты: **требование трейта проверяется
при объявлении класса**, а не при создании экземпляра. Объявлен класс — значит,
он уже проверен.

## Декораторы

| Файл | О чём |
|---|---|
| [decorators.wdl](decorators.wdl) | `@[...]` на функции и классе, метаданные, регистрация и обёртка, порядок применения, `like`, `sys.meta` |

Правило, которое стоит унести из файла: **применяются снизу вверх**, поэтому
не оборачивающие декораторы ставятся ближе к `def`, чем оборачивающие.

## Ошибки и ресурсы

| Файл | О чём |
|---|---|
| [errors.wdl](errors.wdl) | `throw`, `try`/`catch`/`finally`, короткие формы `try?` и `try!`, ловля по классу и по трейту, цепочка `cause`, путь по скрипту |
| [resources.wdl](resources.wdl) | `defer`, `use`, трейт `Closeable`, потоки `sys.io` |

Правило, вокруг которого построены оба файла: **освобождение пишется рядом
с захватом**. Отложенное действие записывается после успешного захвата, поэтому
проверок «а был ли ресурс» не нужно — в отличие от `finally`, который существует
независимо от того, дошло ли дело до `open`.

## Потоки

| Файл | О чём |
|---|---|
| [threads.wdl](threads.wdl) | `th.spawn`, `join`, `interrupt`, `sleep`, `synchronized def`, `th.counter` |
| [threads_pool.wdl](threads_pool.wdl) | пул и `use`, `pool.map`, `pool.submit` с таймаутом и ошибкой, канал, замок, защёлка |

Правило, вокруг которого построены оба файла: **атомарно одно обращение, а не
выражение**. `count = count + 1` из двух потоков теряет обновления, и склеивают
эти два обращения `synchronized def`, `th.lock()` или `th.counter()` — см.
[docs/threads.md](../docs/threads.md).

Чат-сервер из [chat_server.wdl](chat_server.wdl) — тот же приём на живом примере:
клиенты обслуживаются в своих потоках, а общий список защищён `synchronized`.
Он не прогоняется на сборке — занимает порт.

## Встраивание: то, что дала сторона Java

| Файл | О чём |
|---|---|
| [stdlib.wdl](stdlib.wdl) | `pow`, `sqrt`, классы `File` и `Random`, фабрика `File.temp()`, поле класса, состояние экземпляра |
| [embedding.wdl](embedding.wdl) | трейт-контракт от модуля (`json.Serializable`), иерархия нативных классов (`io.Stream`), ошибки библиотек по классам, изоляция запусков |

Правило, вокруг которого построены оба файла: **скрипт не видит разницы**. Класс
на Java — такой же класс, трейт — такой же трейт, требование проверяется на строке
`class`, ошибка ловится обычным `catch` по классу. Разницу видно ровно в одном
месте — в том, что состояние этих классов не переживает свой запуск.

## Тесты на самом языке

Отдельная папка со своим описанием: [testing/](testing) — движок тестов,
написанный на wdl, и полсотни проверок на нём. Заодно это самый плотный пример
работы с ошибками: проверка — обычная функция, которая бросает, а набор —
обычный класс, который ловит.

## Модули

Отдельная папка со своим описанием: [modules/](modules) — `import` в обеих формах,
области видимости, наследование через файлы, загрузка плагина по требованию
и набор сценариев, которые должны падать.

| Файл | О чём |
|---|---|
| [sys.wdl](sys.wdl) | встроенные модули: `sys.json` и `sys.io` — библиотеки на Java, приходящие через `import` |

`sys.net.http` в примерах не показан намеренно: они прогоняются на сборке,
а сеть в ней может быть недоступна. Как он выглядит — в [docs/modules.md](../docs/modules.md).

## Лексер

Эти два файла — единственные, которые не запускаются: они написаны для `--tokens`,
а не для выполнения.

```bash
wdl --tokens examples/lexer-check.wdl
wdl --tokens examples/lexer-errors.wdl
```

| Файл | О чём |
|---|---|
| [lexer-check.wdl](lexer-check.wdl) | все виды литералов и имён, включая кириллические |
| [lexer-errors.wdl](lexer-errors.wdl) | как выглядят сообщения лексера: разбор не прерывается на первой ошибке |

Идентификаторы в примерах английские, комментарии и строки — русские. Кириллица
в именах языком поддерживается (это видно в `lexer-check.wdl`), но в примерах
её не демонстрируют.
