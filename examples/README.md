# Примеры

Каждый файл запускается отдельно и показывает одну тему целиком. Всё, что здесь
написано, **работает**: примеры прогоняются как есть, а строки, которые должны падать,
оставлены закомментированными вместе с текстом ошибки.

```bash
./gradlew :wdl-cli:installDist
wdl-cli/build/install/wdl/bin/wdl examples/hello.wdl

# или без сборки дистрибутива
./gradlew :wdl-cli:run --args="examples/hello.wdl"
```

## Язык

| Файл | О чём |
|---|---|
| [hello.wdl](hello.wdl) | переменные, объекты, массивы, вывод — с чего начать |
| [expressions.wdl](expressions.wdl) | шпаргалка по выражениям: числа, биты, сравнения, обращение |
| [control-flow.wdl](control-flow.wdl) | `if`, `while`, `for`, перебор, `break`/`continue`, области блока |
| [const.wdl](const.wdl) | `const`: заморожено имя, а не содержимое |
| [functions.wdl](functions.wdl) | объявления, `return`, `=>`, анонимные функции, замыкания |
| [defaults.wdl](defaults.wdl) | значения параметров по умолчанию и когда они вычисляются |
| [stdlib.wdl](stdlib.wdl) | `pow`, `sqrt`, классы `File` и `Random` — то, что дало приложение |

## Классы и трейты

Три файла по возрастанию: сначала один класс, потом цепочка, потом контракты.

| Файл | О чём |
|---|---|
| [classes.wdl](classes.wdl) | поля и методы, `this`, конструктор, фабрики, класс как значение, класс внутри функции |
| [inheritance.wdl](inheritance.wdl) | `: Родитель(...)`, `super`, виртуальные вызовы, цепочка из трёх уровней, полиморфизм, `is` |
| [traits.wdl](traits.wdl) | трейт-контракт, готовые реализации, состояние в трейте, несколько трейтов, «побеждает последний», момент проверки требований |

Правило, вокруг которого построен последний файл: **требование трейта проверяется
при объявлении класса**, а не при создании экземпляра. Объявлен класс — значит,
он уже проверен.

## Модули

Отдельная папка со своим описанием: [modules/](modules) — `import` в обеих формах,
области видимости, наследование через файлы, загрузка плагина по требованию
и набор сценариев, которые должны падать.

## Лексер

Эти два файла — единственные, которые не запускаются: они написаны для `--tokens`,
а не для выполнения.

```bash
wdl --tokens examples/lexer-check.wdl
wdl --tokens examples/lexer-errors.wdl
```

| Файл | О чём |
|---|---|
| [lexer-check.wdl](lexer-check.wdl) | все виды литералов и имён, включая кириллические |
| [lexer-errors.wdl](lexer-errors.wdl) | как выглядят сообщения лексера: разбор не прерывается на первой ошибке |

Идентификаторы в примерах английские, комментарии и строки — русские. Кириллица
в именах языком поддерживается (это видно в `lexer-check.wdl`), но в примерах
её не демонстрируют.
